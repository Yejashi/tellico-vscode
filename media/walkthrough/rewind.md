# Checkpoints

Every message you send is a checkpoint. Hover it:

- **Rewind** restores the files the agent changed since, and sets the rest
  of the conversation aside. **Redo** brings both back until you send again.
- **Edit** rewinds and puts the message back in the input box.
- **Fork** starts a new session with the conversation up to that point.

Local models take wrong turns; a clean retry beats arguing in a polluted
context.
