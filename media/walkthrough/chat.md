# The chat

| Type | To |
|---|---|
| `@file` | attach a file (`@file#L3-9` for lines) |
| `!cmd` | run a shell command without a model turn |
| `/` | Magic Context and other slash commands |
| `Enter` while it works | queue a follow-up |
| `Ctrl+Enter` while it works | steer the running turn |
| `Esc` | stop |

The pickers under the input choose **build** or **orchestrate**, the lead
**node**, and the **thinking** level.
